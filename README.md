# FindingStacyOS

"You used to know Stacy, but she's gone now. It's up to you to find her"

A detective game where you have to search through Stacy's laptop to uncover the reason behind her disappearance.


This version does not have any mystery elements yet, but feel free to try out the existing apps for now!

![alt text](image.png)

## Features

- Diary app
    - Has 1 entry from Stacy

- Calculator app

- Paint app
    - Includes a color picker, brush size slider, and clear + fill canvas buttons

- Pink color scheme with gingham background
